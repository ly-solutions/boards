# Argo CD

[`application.yaml`](application.yaml) is a plain Argo CD `Application` that installs the
[Helm chart](../helm/boards) straight from this repository (`path: deploy/helm/boards`) into the `boards`
namespace, with automated sync (prune + self-heal) and `CreateNamespace=true`. The inline `valuesObject` shows S3 on
AWS (IRSA) with OpenID Connect sign-in; every key is documented in the [chart README](../helm/boards/README.md#values).

```bash
# 1. The Secret first — it never goes into Git.
kubectl create namespace boards
kubectl -n boards create secret generic boards-secrets \
  --from-literal=BOARDS_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=BOARDS_OIDC_CLIENT_SECRET='<client secret>' \
  --from-literal=BOARDS_API_TOKENS="$(openssl rand -hex 32)"

# 2. Edit publicUrl, bucket, role ARN, issuer and host in application.yaml, then:
kubectl -n argocd apply -f deploy/argocd/application.yaml
```

Notes:

- **Pin `targetRevision`** to a release tag (`v0.1.0`) instead of `main` so upgrades happen when you choose.
- **Keep generated secrets in `existingSecret`.** Argo CD renders the chart without cluster access, so Helm `lookup`
  returns nothing; a session secret or API token generated by the chart would change on every sync. Either use
  `existingSecret` (as here) or set `auth.sessionSecret` / `auth.apiTokens` explicitly.
- Restart the pod after rotating the Secret (`kubectl -n boards rollout restart deploy/boards`); the chart cannot
  checksum a Secret it does not render.
- boards runs as one replica by design; do not add an HPA.

## Using the OCI chart instead

Once the chart is published to `ghcr.io/ly-solutions/charts/boards`, point the source at the registry instead of Git
(no `path`; `targetRevision` is the chart version):

```yaml
  source:
    repoURL: ghcr.io/ly-solutions/charts
    chart: boards
    targetRevision: 0.1.0
    helm:
      releaseName: boards
      valuesObject: {}   # same values as above
```

Argo CD treats an OCI registry as a Helm repository; register it once with `enableOCI: true` (for a public
registry no credentials are needed):

```bash
argocd repo add ghcr.io/ly-solutions/charts --type helm --name boards-charts --enable-oci
```
